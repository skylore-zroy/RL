## 1. 项目目标

基于作者现有的 RM2026 串联腿闭链平衡机器人模型，建立可复现的强化学习工程。第一版先使用现有机器人验证完整闭环，成功后才进入自研机器人模型阶段。

第一版只支持这一台 COD 机器人，不导入 b2w、A1、Go2 或其他机器人。目标策略需在 Isaac 与 MuJoCo 中稳定执行前进、后退、转向和跨台阶，并使速度误差和跌倒率保持在可接受范围。

## 3. 功能范围

### 3.1 必须实现

- 作者机器人 USD/MJCF 的结构、质量、惯量、闭链与关节映射核对；
- Isaac Sim 5.0 / Isaac Lab 2.2 中的自由基座机器人加载；
- 轮腿平衡、速度指令跟踪、前进、后退和偏航转向；
- 台阶/复杂地形课程学习；
- PPO 并行训练、断点续训、日志、模型导出与可复现实验配置；
- MuJoCo 中独立构造同一观测、动作、控制周期和关节顺序；
- Isaac 到 MuJoCo 的 sim-to-sim 回放、批量指标和失败记录；
- 两套容器化环境，使支持的 NVIDIA Linux 主机无需手工配置 Python/CUDA/仿真依赖。

### 3.2 当前不做

- 自研机器人模型；
- 实物部署 sim-to-real；
- 其他机器人兼容；
- 在本机 8 GB 显存上进行 Isaac Sim 5.0 正式训练。

## 4. 技术架构

| 环节 | 固定版本/基础 | 职责 |
| --- | --- | --- |
| 训练与 Isaac 验证 | NVIDIA `isaac-lab:2.2.0`，内含 Isaac Sim 5.0 | 并行环境、PPO、地形课程、USD 运行验证 |
| 独立验证 | Ubuntu 22.04 / MuJoCo 3.2.6 | 策略回放、动力学交叉检查、指标统计 |
| 代码与构建定义 | GitHub `git@github.com:skylore-zroy/RL.git` | 代码、配置、文档、自动构建定义 |
| 容器发布目标 | GitHub Container Registry（待许可证确认） | 支持主机拉取后直接运行 |

Docker 镜像是 Linux 环境，与开发者是否在 Windows 上查看模型无关。同一训练镜像可在 WSL 2、Ubuntu 主机或 Linux GPU 服务器使用，前提是主机满足 NVIDIA 驱动、Docker 和 GPU 容器支持要求。

## 5. 物理与控制一致性要求

Isaac 与 MuJoCo 必须显式统一：

- 15 个刚体的质量、质心、惯量；
- 14 个树关节和 4 个闭链约束；
- 6 个主动执行器：左右前腿、左右后腿、左右车轮；
- 关节方向、零位、限位、阻尼和动作缩放；
- 控制频率、仿真步长、观测历史和策略推理频率；
- 地面摩擦、碰撞几何、轮胎接触和随机化范围。

已知数据边界：USD 总质量 19 kg、底盘 11 kg；USD 没有有限关节限位，暂以作者 MJCF 限位为准。真实电机扭矩/速度、减速比、轮地接触参数和传感器噪声仍需硬件资料或标定。

## 6. 验收口径

以下为第一版基线，正式训练后根据实测冻结：

| 指标 | 基线目标 |
| --- | --- |
| 指令速度范围 | 0.2–1.0 m/s，含正向与反向 |
| 单次评测 | 20 s |
| 每种场景随机评测 | 100 次 |
| 平均绝对速度误差 | 不高于 0.15 m/s |
| 最大跌倒率 | 不高于 5% |
| 转向 | 正负偏航角速度均可稳定跟踪 |
| 台阶 | 从低台阶开始课程训练，最终高度以稳定通过实测冻结 |
| Sim-to-sim | 同一导出策略不重新训练即可在 MuJoCo 运行 |

“模型能够打开”只算资产验证，不算策略验收；“不固定且会受重力运动”只算自由基座物理验证。
